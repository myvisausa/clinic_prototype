# Browser reference capture index

Status: page/tab capture pass includes the eight clinical record tabs, all three dental-chart sub-tabs and both treatment sub-tabs. Ana was explicitly confirmed fictional by the user; the earlier approval block was resolved on retry.

Source: the running application at localhost:3001, compared with dynamic-baseline at 127.0.0.1:8765. Captured by navigating the rendered UI, not by reconstructing source files. The inventory follows Home, Clinic, Engage, Settings, then the additional Library found in All pages. No prototype implementation changed.

## How to use

Open index.html for a side-by-side gallery, or choose a view below. Every listed view has original.jpg, baseline.jpg, DOM snapshots (.txt), URL/timestamp metadata (.json), and differences.md. Some tall forms have additional middle/lower screenshots. Read DOM snapshots alongside screenshots for content below the viewport. Captures represent page/tab structure, not every row, contact, date, filter combination or action dialog.

When the baseline has no matching page or nested tab, its nearest existing parent view is captured as absence evidence. It is NOT an equivalent page. Follow the note before reusing any image.

## Capture limitations

- Original is Spanish; baseline is English. Separate translation differences from structural differences.
- Both used a nominal 1366×768 viewport override, but original retained 90% origin zoom (approximately 1517×853 CSS pixels) while baseline was at 100%. Screenshot output includes extra white space on original captures. These are content/layout references, NOT normalized pixel-diff fixtures.
- Backend load errors, disabled channels and missing integration states are captured as observed; they do not establish that a collection is empty.
- Initial cached screenshots were discovered and replaced. Original JPEG hashes are checked for accidental duplication.
- Patient directory and Ana's eight clinical tabs are captured. Dental chart includes Enter, Procedure progress and Initial state; Treatments includes Plans and Estimates. No records were modified.
- Messenger and Instagram inbox channels were disabled; no content capture is claimed.
- The Integrations Google Calendar link redirected to Clinical setup / Clinic, already captured.
- External legal/privacy pages, record-specific detail flows, edit/create dialogs, every table pagination page, and all dropdown options are outside this page-and-tab pass. My availability is included because it contains two additional tabs.
